# 見積書自動作成機能 使い方マニュアル（担当者向け）

Googleフォームに届いたお問い合わせから、**概算お見積書をGoogleドキュメントで自動作成**する機能です。
お客様への送付は、必ず担当者が内容を確認してから行います。

---

## 1. この機能でできること

- フォーム回答から、自動見積が可能な案件を判定する
- 対象案件の**概算お見積書（Googleドキュメント）を自動生成**する
- 施設の住所から**交通費を自動概算**する
- フォーム未記入の項目は**仮の値で補完**して見積を作成する（送付前に要確認）
- お客様へ送るための**メール本文案**を自動で用意する

PDFが必要な場合は、生成したDocを開いて `ファイル → ダウンロード → PDF` で書き出します。

---

## 2. スプレッドシートのタブ構成

| タブ | 役割 | 直接編集 |
|---|---|---|
| **フォームの回答 1** | フォーム回答が自動で溜まる元データ | しない |
| **見積処理管理** | 見積作成のメイン管理表。ここで操作する | ステータス確認・行選択 |
| **保留一覧** | 自動見積できない案件の一覧 | 担当者が個別対応 |
| **料金ルール** | 単価・係数の設定表。**E列を変えると計算に反映** | 金額の変更のみ |
| **使い方** | 本マニュアル | ― |

---

## 3. 基本の操作フロー

```
① 見積処理管理を更新   →   ② 対象行を選択   →   ③ 見積書(Doc)を生成
        ↓                                              ↓
  自動判定・料金計算                          Doc・交通費・メール本文が入力される
                                                       ↓
                                        ④ Docを確認（必要ならPDF化）→ ⑤ 送付
```

### 手順（詳細）

1. 対象のスプレッドシートを開く
2. 上部メニュー **`見積自動化`** → **`見積処理管理を更新`** をクリック
   - フォームの新しい回答が読み込まれ、`見積処理管理` と `保留一覧` が最新化されます
3. **`見積処理管理`** タブを開く
4. `処理ステータス` が **`作成済み・要確認`** の行を探す
5. 見積書を作りたい行を**1行クリックして選択**する
6. メニュー **`見積自動化`** → **`選択行の見積書(Doc)を生成`** をクリック
7. 完了メッセージが出たら、その行の以下の列が自動入力されます
   - `見積書ファイル名` / `見積書URL`（Googleドキュメント）
   - `交通費（税抜）`
   - `メール下書き本文`
8. `見積書URL` を開いて**内容を目視確認**する
9. PDFが必要なら、Docの `ファイル → ダウンロード → PDF ドキュメント(.pdf)` で書き出す
10. 問題なければ、`メール下書き本文` を使ってお客様へ送付する

> ⚠️ 見積書の生成は必ず **`見積処理管理` タブで行を選択**してから実行してください。
> 他のタブやヘッダー行を選択して実行するとエラーになります。

---

## 4. 処理ステータスの意味

| ステータス | 意味 | 対応 |
|---|---|---|
| **作成済み・要確認** | 自動で概算見積書を作成できる | 行を選択して見積書を生成 |
| **保留** | 自動見積書は作成しない | `保留一覧` の理由を確認し個別対応 |

### 保留になるケース（3種類）

不足項目は自動で補完するため、保留になるのは**サービス内容の判定**によるものだけです。

- **清掃サービスのみ** … 管理は不要で清掃だけの希望（将来的に別清掃会社紹介で対応予定）
- **施設管理運営代行が未選択** … 対象サービスが定まらない
- **複数棟・複数物件の可能性** … どの棟を1件とするか特定できない

---

## 5. フォーム未記入項目の自動補完（仮設定）

物件平米数・収容人数・間取り・グレード・住所がフォームで空欄でも、**保留にせず仮の値で見積を作成**します。

| 項目 | 未記入時の仮の値 |
|---|---|
| 物件平米数 | 100㎡ |
| 希望最大収容人数 | 8名 |
| 間取り | 3LDK |
| 施設グレード | 標準 |
| 住所 | 「未確認」表記（交通費は暫定2,000円） |

- どの項目を仮設定したかは、`見積処理管理` の **`仮設定項目`列**（担当者用）に記録されます。
- お見積書（Doc）とメール本文には、**お客様向けの表現**で「一部は仮の条件で概算」と表示されます。

> ✅ `仮設定項目` に何か入っている案件は、**送付前に必ず実際の値を確認・修正**してください。

---

## 6. 交通費の自動計算（清掃単価に合算）

施設の住所をもとに、ホームページのシミュレーターと同じロジックで交通費を自動概算します（最寄り拠点までの距離に応じた金額）。

**交通費は「一棟 清掃サービス 基本単価（リネンクリーニング込）」に合算され、見積書上は交通費として個別表示しません。**

- 対応エリア内の住所 … 距離に応じて自動計算。拠点圏内なら加算なし。
- 住所が未確認／対応エリア外／住所を特定できない … **暫定2,000円**を清掃単価に合算（`仮設定項目`に記録）。
- 交通費は実費精算のため、確定時に金額が変わる場合があります。

> 💡 算出した交通費の金額は、確認用に `見積処理管理` の **`交通費（税抜）`列**（担当者用）に表示されます。清掃単価の内訳を確認したいときはこの列を参照してください（お客様の見積書には出ません）。

---

## 7. 料金の変更方法（料金ルール タブ）

単価・係数を変えたいときは **`料金ルール` タブの「値」（E列）** を書き換えます。

1. `料金ルール` タブを開く
2. 変更したい項目の行を探す（`キー`列・`条件/説明`列で判別）
3. **E列（値）** を書き換える
   - 金額は `¥75,000.00`、係数は `1.25`、率は `15.00%` の形式で入力
4. `見積自動化` → `見積処理管理を更新` を実行 → 計算に反映されます

> ⚠️ `キー`列（B列）は計算プログラムと対応しています。**行の削除やキー名の変更は、担当者間で確認してから**行ってください（金額の変更のみなら安全です）。

代表的な項目：

- `area_*` … 面積帯ごとの清掃基本単価
- `grade_luxury` … 高級グレードの係数（現在 1.25）
- `default_under_3ldk` / `three_ldk_or_more` / `villa_or_200sqm` … 初期設定費
- `permit_minpaku` / `permit_hotel_or_simple_lodging` … 許可取得サポート
- `management_rate` … 管理料率（現在 15%）

## 8. お客様への送付について

- 現時点では**自動送信は行いません**。
- Docを目視確認（必要ならPDF化）したうえで、担当者がメール本文を確認・調整し、ファイルを添付して送付します。
- メール本文案は `見積処理管理` の `メール下書き本文` 列に自動作成されます。文面は自由に調整してください。

### 見積書の確認ポイント

- 宛名が正しいか（法人は「御中」、個人は「様」）
- 施設所在地・面積・収容人数・間取りが正しいか（`仮設定項目`に注意）
- 初期設定費・清掃単価（交通費込み）・追加費用が想定と大きくズレていないか
- サービス内容の表が崩れていないか
- `見積書URL`（Doc）が入力されているか

---

## 9. よくあるトラブルと対処

| 症状 | 確認すること |
|---|---|
| メニュー `見積自動化` が出ない | スプレッドシートを再読み込みする |
| 「対象の管理行を選択してください」エラー | `見積処理管理` タブでデータ行（ヘッダー以外）を選択しているか |
| 「作成済み・要確認の行のみ生成できます」エラー | 選択行が保留（`保留`）になっていないか |
| 交通費が「暫定2,000円」になる | 住所が粗い／対応エリア外の可能性（想定内の挙動。必要なら住所を補って再生成） |
| 料金ルールを変えても金額が変わらない | `料金ルール` タブ名・`キー`/`値`の見出し・キー文字列が正しいか。更新後に「見積処理管理を更新」を実行したか |
| 権限の承認画面が出た | 内容を確認して許可する（Drive保存・住所検索・ドキュメント編集の権限） |

## 10. 初期設定（初回のみ・管理者向け）

スクリプトを新しいスプレッドシートに導入・更新する場合の作業です。通常の運用では不要です。

1. `拡張機能` → `Apps Script` を開く
2. `Code.gs` の内容を最新版に差し替えて保存
3. Apps Scriptエディタ左の `サービス（＋）` から **`Drive API`** を識別子 `Drive` のまま追加して保存（Doc変換に必須）
4. スプレッドシートを再読み込み
5. 初回実行時、Google Drive保存・外部通信（住所検索）・ドキュメント編集の**承認画面**が出たら許可する

---

### 補足

- 見積書のGoogleドキュメントは、スプレッドシートと同じフォルダ内の **`Minpaku Resort 見積書Doc`** フォルダに保存されます。
- 本見積はあくまで**概算**です。物件確認・運用条件・設備状況により最終金額が変動する場合があります。
