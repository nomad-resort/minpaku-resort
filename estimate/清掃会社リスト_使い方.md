# 提携清掃会社リスト 使い方

`清掃会社リスト.csv` は、清掃のみ問い合わせを紹介する提携清掃会社の管理表。
Googleスプレッドシートへ取り込んで使う（`ファイル → インポート → アップロード`）。

## 各エリア 3〜5社を目標に埋める

現状は全43エリアを1行ずつ用意している。**1エリアにつき3〜5社**を確保したいので、
会社を追加するときはそのエリアの行を**コピーして行を増やす**。

## 列の意味

| 列 | 内容 |
|---|---|
| エリア | HP掲載の対象エリア（付録の43地域） |
| 会社名 | 清掃会社の正式名称 |
| 対応可否 | ◯（対応可）／△（条件付）／×（不可）。一斉共有の対象は◯のみ |
| 優先順位 | 同一エリア内の連絡順の目安（1が最優先）。※一斉共有だが、実績評価に使う |
| 連絡先メール | リード共有メールの送信先 |
| 電話番号 | フォールバック時の直接打診用 |
| 担当者名 | 先方の窓口担当 |
| 民泊清掃実績 | 有／無／不明。民泊・短期賃貸の清掃経験があるか |
| 提携ステータス | 未接触／打診中／提携済／見送り |
| 直近の反応日 | 最後にリードへ反応した日（品質評価の材料） |
| 備考 | 対応エリア範囲・最低料金・レスポンスの速さなどメモ |

## 選定の目安（品定めのポイント）

- 民泊・短期賃貸の清掃実績がある（チェックアウト後の短時間ターン対応に慣れているか）
- レスポンスが速い（48時間ルールで反応してくれるか）
- 対応エリアの範囲が広い
- 料金・品質が安定している

対応が悪い・クレームが出た先は `対応可否` を×にして共有対象から外す。

## 立ち上げ順

全エリアを同時に埋める必要はない。**問い合わせが来たエリア＋既存拠点のあるエリア（別府・湯布院など）から**優先的に3〜5社を確保していく。

## 記入済みリストについて（2026-07-22 一次調査）

Web検索で**実在が確認できた候補のみ**を記入済み。連絡先メールは各社サイトが問い合わせフォーム中心のため、原則**URLを備考に記載し、メール欄は空欄（要確認）**にしている。実際の提携前に、各社サイトから連絡先・料金・対応可否を確認すること。

- **「全国対応」行**（先頭3社：M's B／Kirei One／おそうじ革命）… どのエリアでも紹介候補に使える。地元業者が少ないエリアの底支え。
- **会社名が空欄で備考に「要確認」とある行**… その地域で専業の民泊清掃会社を確定できなかったエリア。備考のアグリゲータ（くらしのマーケット／ゼヒトモ等）や近隣市の業者、全国対応3社で対応する。
- 沖縄・京都・大阪・北海道・富士五湖・箱根/熱海は専業が多く、候補も厚め。東北・山陰・四国の一部は候補が薄いので追加調査の余地あり。
